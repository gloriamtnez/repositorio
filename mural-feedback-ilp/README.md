# Versión ILP del mural de feedback

Versión visual basada en el sistema de diseño del test de asertividad publicado: fuentes Jost e Inter, azul marino `#0f2744`, amarillo `#ffe216`, tarjetas blancas redondeadas y sombras suaves.

Reutiliza la lógica, la configuración de Firebase y los recursos originales de `../mural-feedback/`. Para publicar en GitHub Pages, conserva ambas carpetas en el mismo repositorio y usa `mural-feedback-ilp/index.html` como URL de acceso.
